# Transcribe

Windows x64 / Windows PowerShell 5.1 用のローカル日本語文字起こしツールです。リアルタイムには多言語 Whisper small、録音後の手動清書には Whisper large-v3-turbo を使います。Tool Rack や他のリポジトリは不要です。

## フォルダ同梱・オフラインで起動

**Whisper small / large-v3-turbo の重み、トークン表、Silero VAD、実行用 DLL をすべてこのフォルダに同梱しています。利用PCでの追加ダウンロードやモデル取得コマンドの実行は不要です。初回もインターネットに接続せず利用できます。** Python環境、Git LFS、外部のモデルキャッシュにも依存しません。

フォルダ全体を固定の書き込み可能な場所へ展開し、`transcribe.vbs` で起動してください。コンソール付きの診断起動は `transcribe.cmd` です。Windows Script Host が使えない環境では `transcribe.cmd` を使います。画面を開いただけでは録音しません。

`install.bat` はエクスプローラの空白とデスクトップの空白に右クリックメニューを登録します。現在のユーザーのHKCUだけを使い、管理者権限は不要です。Windows 11では「その他のオプションを表示」側のメニューです。配置を移動したら移動先で再実行してください。

## 同梱モデルの準備

大きなONNXモデルは既存の配布方式と同様、75 MiB以下の `.part01`, `.part02`, ... に分割してGitに実体を格納しています。LFSポインターではありません。各モデルの `.manifest` には順序・長さ・SHA-256を記載しています。

初回の「録音開始」ではsmall、初回の「清書を実行」ではlarge-v3-turboを、同じモデルフォルダ内で自動結合・検証します。これはローカルのファイル処理だけです。画面は開いたまま状況を表示し、正常な結合済みファイルは次回から再利用します。破損した結合済みファイルは、正常な同梱パーツがそろっていればローカルで再作成します。パーツ自体が欠落・破損している場合は、外部取得せずエラーを表示します。

分割モデルに加え、結合後のモデル約1.4 GB分の空き容量が必要です。既存モデルを修復する際は、置換対象のモデル1ファイル分の一時領域も必要になります。フォルダを移す際はパーツ・トークン表・マニフェストを含めて全体を移してください。

## 操作

「録音開始」→「録音停止」→残りの認識処理が完了してから「清書を実行」の順に操作します。モデルの準備中はまだ録音していません。「録音中」の表示になってから話してください。

リアルタイムはsmallで発話区間ごとに認識します。発話は最大約6秒で区切り、表示には区切り待ちと推論時間がかかります。清書は保存した録音全体をlarge-v3-turboで再認識し、最大約25秒の発話区間を使います。清書は手動実行のみで、要約やLLMによる文章校正ではありません。

リアルタイムと清書は別タブです。コピー・クリア・保存は表示中のタブに作用します。失敗・中止で既存の清書結果は上書きしません。smallとturboを同時には保持せず、処理後に解放します。推論・モデル準備の途中は即時強制終了せず、安全に処理が戻った時点で中止します。

## 保存とプライバシー

清書のため、音声を `output/recordings` にPCM WAVで保存します（約115 MB/時）。推論の遅れだけでは音声キューから捨てませんが、ディスク不足などの保存エラーは別途表示します。音声は終了・クリア・アンインストールでも自動削除しません。不要な録音は利用者が削除してください。

テキストは自動保存しません。必要なタブを「保存」してから終了・新規録音してください。保存先はこのフォルダの `output/transcribe_<日時>_<ID>.txt` です。音声・テキストを外部送信する処理はありません。エラーログは `%LOCALAPPDATA%\pub-transcribe\logs` に残ります。

## 検証

Windows PowerShell 5.1で、次を個別に実行できます。

```powershell
.\test\check.ps1 -Runtime
.\test\engine.ps1
.\test\bundle.ps1
.\test\token-validation.ps1
.\test\native-vad.ps1
.\test\offline-models.ps1
```

`test/bundle.ps1` は小さなテスト用データで、欠落・破損・並び順・同時準備・失敗時の既存ファイル保持などを検証します。`test/offline-models.ps1` は同梱の実モデルを結合し、両モデルの読み込み・無音入力での推論を確認します。実音声は `test/model-runtime.ps1 -Wav <16kHz mono PCM16 WAV>` で試せます。

CIではアプリを実行するPowerShellプロセスの送信通信を遮断し、結合済みモデルがない状態から両モデルを使う経路を試験します。`test/run-offline-ci.ps1` はGitHub Actions専用です。通常の利用PCではファイアウォールを変更しません。Git上の全配布ファイルの検証は `test/checksums.ps1`、開発時のチェックサム更新は `git add` 後の `python test/update-checksums.py` です。

実マイク、日本語音声の認識精度、長時間録音、利用PCごとの速度・デバイス・権限は別途実機確認が必要です。無音入力の試験は認識精度の保証ではありません。

## 削除とライセンス

`uninstall.bat` はこのコピーが登録した背景メニューだけを解除します。録音・テキスト・モデルは削除せず、移動先の新しい登録も消しません。

モデルの出典は `src/app/model/SOURCE.md`、第三者ライセンスは `src/app/THIRD-PARTY-NOTICES.md` と `src/app/licenses/` を参照してください。
